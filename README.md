# Coin Collector

A browser-based coin-clicking game developed as a JavaScript pair assignment.

## Overview

Coin Collector is an interactive game where players click a coin to earn coins and purchase upgrades to improve their progress.

## Features

- Click the coin to increase your click count and score.
- Purchase upgrades, including Double, Multiply, Auto Click, and Speed Up.
- Track your coin balance and number of upgrades.
- Explore the game's rewards and help features.

## Technologies

- HTML
- CSS
- JavaScript

## Running the Game

1. Download or clone this repository.
2. Keep `increments.html`, `increment.css`, `increments.js`, and `coin.png` in the same folder.
3. Open `increments.html` in a web browser.
